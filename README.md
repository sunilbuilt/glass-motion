# Glass Motion

A Claude Code skill for reel edits: liquid-glass pills, expo-out motion, typing-style captions.

Install: `git clone https://github.com/sunilbuilt/glass-motion ~/.claude/skills/glass-motion`

Not included: the reference reels (`assets/ref/`) and the sound effects (`assets/sfx/`) that `SKILL.md` mentions. They belong to the original creator. Use your own reference clips and SFX in those folders.
